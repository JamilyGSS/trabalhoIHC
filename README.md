# Trabalho 2 de IHC
## Avaliação de Usabilidade — Sistema de Pedidos de uma Confeitaria 🍰

### Descrição
Interface web que permite aos clientes consultar produtos de uma confeitaria, visualizar detalhes, personalizar produtos, adicionar itens ao carrinho, escolher a modalidade de entrega ou retirada, selecionar data e horário disponíveis para entrega ou retirada, escolher a forma de pagamento e finalizar o pedido.
